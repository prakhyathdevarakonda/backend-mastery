# 06 - Self Introspection (Basics / Mid / Senior)

Use this after each week. Be honest.

## Level 1: Basics Check

Mark Yes/No:

- Can I explain each of the 5 problems in plain language?
- Can I explain root cause, not just definition?
- Can I reproduce at least 3 of the 5 in code?
- Can I explain why one fix is better than another?
- Can I run tests and verify behavior correctly?

If 3 or fewer are Yes, repeat foundational practice.

## Level 2: Mid-Level Check

Mark Yes/No:

- Can I design API contracts with validation and error responses?
- Can I choose lock/isolation strategy for a real scenario?
- Can I debug a failing path using logs and metrics?
- Can I explain Spring Security context lifecycle?
- Can I explain where AOP helps and where it hurts?
- Can I reason about async thread pool starvation?

If 4 or fewer are Yes, focus on system behavior and debugging labs.

## Level 3: Senior-Ready Direction Check

Mark Yes/No:

- Can I prevent these issues through design and reviews?
- Can I explain tradeoffs to both engineers and non-engineers?
- Can I design for reliability and operability, not only correctness?
- Can I identify bottlenecks and tune them with data?
- Can I define observability before incidents happen?
- Can I mentor someone through root-cause analysis?

If 4 or fewer are Yes, continue practical project evolution before targeting senior interviews.

## Reflection Template

Write this every week:

1. What did I learn this week?
2. What broke and why?
3. Which fix did I choose and why?
4. What evidence proved the fix?
5. What interview question can I now answer better?
6. What will I practice next week?
