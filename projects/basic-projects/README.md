# Basic Projects Track

Small, fundamentals-first project specs to make interview prep structured and practical.

## Why this track

Your existing `wallet-service` and `ledger-service` already cover many intermediate topics.  
This track adds simple, focused projects so you can build strong design fundamentals and explain tradeoffs clearly.

## Projects

1. `01-url-shortener-fundamentals.md`
2. `02-rate-limiter-service.md`
3. `03-job-queue-worker.md`
4. `04-cache-aside-catalog.md`
5. `05-leaderboard-service.md`

## How to use each spec

For each project:

1. Read requirements and constraints.
2. Sketch high-level design on paper/draw.io.
3. Design APIs and schema.
4. Identify bottlenecks and failure modes.
5. Explain tradeoffs out loud in interview format.

## Interview drill format (30-40 min)

- 5 min: clarify assumptions
- 10 min: high-level design
- 10 min: APIs + data model
- 10 min: scale/failure/tradeoffs
- 5 min: recap and alternatives
