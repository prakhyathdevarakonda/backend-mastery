# Steering Document

This file tells you how to use this repository even without any AI agent.

## Primary Goal

Become interview-ready and production-aware in Java + Spring Boot backend engineering.

## Daily Method (60-90 minutes)

1. Pick one problem or concept.
2. Try without solution.
3. Implement or reproduce in wallet project.
4. Verify with test or runtime evidence.
5. Write a short reflection.

## Interview Practice Method

For each topic, prepare:

- 30-second summary
- 2-minute deep answer
- one practical example from your project

## If You Share This With ChatGPT

Best prompt style:

1. "Ask me interview questions on Problem X."
2. "Challenge my answer with follow-up questions."
3. "Rate me on root cause, tradeoff, testing, and production readiness."
4. "Give me one improvement target for next session."
